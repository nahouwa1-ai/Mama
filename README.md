# مبيعات الأكياس - تطبيق ويب (PWA)

يعمل بدون إنترنت بعد أول فتح، ويُثبَّت على الهاتف كتطبيق.

## الملفات (ارفعها كلها في نفس المكان)
- `index.html` : التطبيق
- `manifest.webmanifest` : بيانات التطبيق (الاسم، الأيقونة، الألوان)
- `sw.js` : يحفظ الصفحة للعمل بدون إنترنت
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` : الأيقونات

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع كل الملفات أعلاه.
2. Settings ← Pages ← Branch: `main` / `(root)` ← Save.
3. بعد دقيقة افتح الرابط `https://USERNAME.github.io/REPO/` في Chrome على الهاتف.
4. افتح الصفحة مرة واحدة مع الإنترنت، ثم القائمة ⋮ ← **تثبيت التطبيق** (أو إضافة إلى الشاشة الرئيسية).

## عند تعديل التطبيق
بعد تعديل `index.html` غيّر رقم الإصدار في أول `sw.js` (`bags-v1` ← `bags-v2`) ثم ارفع الملفين، وسيصل التحديث عند الفتح التالي.
